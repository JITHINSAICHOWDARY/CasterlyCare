# CasterlyCare — Design Tokens 2.2.1

## Identity
- Primary crimson: `--color-crimson`
- Deep crimson: `--color-crimson-dark`
- Royal gold: `--color-gold`
- Light gold: `--color-gold-light`
- Parchment canvas: `--color-parchment`
- Ink: `--color-ink`

## Surfaces
- `--color-surface`
- `--color-surface-soft`
- `--color-parchment-wash`
- `--color-parchment-deep`

## Typography
- Display: `Fraunces`
- Body/UI: `Inter`

## Radii
- xs: 4px
- sm: 6px
- md: 10px
- lg: 14px
- pill: 999px

## Elevation
- panel: subtle healthcare-card elevation
- panel-hover: restrained lift on interactive surfaces
- modal: deep overlay elevation
- focus: gold accessibility ring

## Usage rule
Components should reference these variables rather than introducing ad-hoc crimson, gold, parchment, border, text, radius, or shadow values.
